# Housing Market AI Estimator

A lightweight, modular vanilla JavaScript application demonstrating an end-to-end data pipeline and a machine learning regression model (k-Nearest Neighbors) built from scratch.

## Features
- **Data Ingestion & Management:** Structured JSON training dataset representing historical real-estate transactions.
- **Machine Learning Engine:** Custom implementation of Euclidean distance calculation and k-NN regression in ES6 modules.
- **Interactive Interface:** Responsive UI built with Tailwind CSS providing real-time property valuation estimates.

## Tech Stack
- HTML5, CSS3, Tailwind CSS
- Vanilla JavaScript (ES6 Modules)
- Git & GitHub Version Control
